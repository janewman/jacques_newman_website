- Helped build shared accessibility infrastructure for browser UI and web
  content through the
  [ViewsAX refactoring, including a shared UI layer and cache][viewsax].
- Delivered Windows UI Automation and text-navigation improvements for Narrator
  and other assistive technologies: UIA tree testing, ignored-node support,
  text ranges, AX mode management, and event reliability.
- Built accessibility telemetry, performance instrumentation, fuzzers, and
  automated tests to inform investment decisions and catch regressions;
  supported Edge, Chromium, WebView2, and partner teams on platform integration.
- Led Accessible Shopping Navigation from architecture and user research through
  prototyping and experimentation, then recommended against shipping based on
  the results. Lead inventor on [U.S. Patent 12282522, “Assistance user
  interface for computer accessibility.”][shopping-patent]
